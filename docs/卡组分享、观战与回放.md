# multicolor:arena 1.0 · 卡组分享、观战与回放

本次更新仍使用正式版本号 1.0。联机双方及观众必须使用本次同一个发行包，规则指纹会拒绝旧包。

## 卡组文件

第一次打开 EXE 时，在 EXE 所在文件夹创建以下目录。开发项目直接运行时则在项目根目录创建。

```text
MulticolorArena.exe
MulticolorArena.pck
deck/
  预设卡组/
    四个预先保存的卡组.mdeck
replay/
```

`.mdeck` 使用 UTF-8 JSON，包含格式标识、版本、卡组 ID、名称、自机、主牌和副牌。每个文件是一副卡组，可直接发给别人。接收方放到自己的 `deck` 目录后，重新进入“编辑牌组”即可看到；也可放在其子目录内。文件名可以更改，游戏内名称读取文件中的 `name`。

编辑后点击“保存”更新该卡组对应文件，新建卡组保存在 `deck` 根目录。保存前仍检查自机、主牌最多 70 张、副牌最多 10 张和已知卡牌。对战所需的严格 50 张检查沿用房间或人机设置。

损坏、超大或包含未知卡牌的文件会单独提示，其余合法卡组照常加载。两份内容相同、ID 相同的副本仅显示一次；内容不同的同 ID 文件会分别显示。保存留下 `.bak` 备份；删除卡组将文件改为 `.deleted`，组卡器不再读取。初始化标记防止主动删除的预设卡组在下次启动时复活。

发行版首次运行会迁移旧 `user://decks.json` 的已有卡组，不覆盖手动放入的同 ID 文件。旧文件保留；今后以 `deck` 中的文件为准。设置、联机身份和恢复记录仍在原用户数据目录。

## 观战

在“联网对战”的房间列表点击“观战”，或输入房主 IP 和对战端口后点击“观战”。不占用双方玩家席位，最多 4 名观众，可中途加入。视角以房主在下方呈现，只展示公开信息；双方手牌与牌库保持卡背，公开展示卡牌的动画照常播放。

观众可查看卡牌、公开卡堆、生命、堆叠和对局流程记录，不能出牌、换牌、调度、支付或投降。观众离开或网络较慢不会暂停玩家。

观战独立使用 **对战端口 + 1** 的 UDP 端口。例如默认对战端口为 47861，观战端口为 47862。通过虚拟局域网时同样需要这两个端口互通。若观战端口被占用，对战仍可进行，自动房间列表的观战按钮不可用。

房主至多每 200 毫秒构建一次观战状态，所有观众共享一次投影计算；传输压缩且总发送预算约为每 200 毫秒 48 KB。观众自己的确认仅控制自己的发送队列，绝不参与玩家同步确认。慢观众会跳过过时动画，追上最新权威状态，公开流程记录保留。观战仍会占用房主部分 CPU 和带宽，无法承诺零影响。

## 断线后等待重连

检测玩家掉线后锁住行动，保留战场查看。等待期间随时可以选择“不再等待，离开对局”。前 30 秒显示重连倒计时；满 30 秒后另可选择继续等待。选择继续等待后不会再自动结束对局，客机仍会自动尝试重连，双方也可手动恢复原对局。选择离开则结束本机等待，不给任一方计胜负；离开的一方不能再恢复该对局。

按用户确认的朋友间测试方案：房主判客机掉线负；客机失去房主时，判房主负并明确标记“本地记录”。纯局域网无第三方裁决，双方网络互断时两端可能各自判胜；本地记录不作为统一赛事结果。后续接入权威服务器可统一裁决。

## 回放

人机单局结束、联网 BO1 结束或 BO3 整场决出胜负时，询问是否保存回放。BO3 局间和断线后主动离开时不询问。选择保存后在 `replay` 中生成一份 `.mreply`，包含本次录制的整场各局；不保存则不生成分享文件。观众保存的是从其加入开始的公开视角。

主界面点击“对局回放”可播放文件。支持播放/暂停、上一步/下一步、进度定位、速度选择及查看战场、卡堆、流程记录。按钮位于右下方，不覆盖右侧堆叠。

回放按录制端当时可见的视角保存：玩家能看到自己的手牌，观众看不到双方隐藏牌；不会在对局结束后自动公开对手的隐藏信息。文件记录实际规则状态、数值和展示事件，播放时不再运行规则结算或 AI，避免重新随机产生不同结果。联网录制包含各局分数和开局硬币，短暂重连延续同一录制；进程恢复尝试加载本机的回放恢复记录。缺少本机恢复记录时，不能补回未录下的部分。

文件使用带 SHA-256 校验的二进制容器，帧数据采用 Zstandard 压缩；不执行文件中的代码。最大文件 128 MiB、最大单帧展开 16 MiB、累计展开 512 MiB、最多 50000 步。损坏或不同规则版本的文件会拒绝播放；分享回放时请使用同一发行包。回放引用本游戏已有卡图，不重复包含整套图片。

## 双机及三机验收

1. 两台新目录运行游戏，确认各生成四份预设 `.mdeck` 与 `replay` 文件夹。保存并分享一副新卡组，对方重新进入编辑器应看到。
2. 房主与客机开始 BO3，第三台电脑用“观战”加入。比较回合、生命、堆叠、指示物和公开记录；双方手牌始终不泄露。
3. 观众断网、退出或重进时，两名玩家继续行动。玩家断网则锁住双方流程；30 秒后可继续等待原玩家重连，也可不再等待并离开。
4. BO3 第一、第二局不出现保存回放提示；整场结束出现一次。保存后重新启动，通过主界面打开 `.mreply`，核对跨局比分、硬币、攻击、阻挡、伤害、符卡响应和结束结果。
5. 开发侧已覆盖本机 ENet 多端及 Godot 图形测试；真实双机/三机、防火墙与异地虚拟网络仍需实际设备验证。
