# Android、Wi-Fi 与内网穿透联机

Android 与 PC 使用同一套 ENet/UDP 对局协议。双方须安装由同一份规则与卡牌数据构建的游戏版本。房主创建房间后接受加入申请，客机再选卡组并准备。

## 同一 Wi-Fi

1. 两台设备接入可以互通的同一 Wi-Fi 或热点。访客网络、AP 隔离会阻止设备互访。
2. 房主在「联机对战」选择「所有网卡」，保留 UDP 对战端口 47861，创建房间。
3. 客机可点击「发现的 Wi-Fi 房间」中的房间。列表为空时，输入房主显示的 Wi-Fi IPv4 地址，例如 `192.168.1.17`，点击「加入」。发现列表依赖 UDP 广播；列表为空不代表直连一定失败。
4. 房主接受申请。若连接超时，检查地址、端口、防火墙和 Wi-Fi 隔离设置。

## 跨网络连接

使用能转发 **UDP** 的虚拟局域网或内网穿透软件。房主监听「所有网卡」，对战使用本机 UDP 47861；客机填房主的虚拟 IP，或者填穿透软件提供的 `域名:外部UDP端口`。地址框也接受 `udp://域名:端口` 和 `[IPv6]:端口`。纯 HTTP、HTTPS 或仅 TCP 的隧道无法承载本游戏的 ENet 连接。

如果穿透软件使用端口映射，将外部 UDP 端口映射到房主的对战端口。观战单独使用对战端口加 1；要跨网络观战，还需把对应的外部端口加 1 映射到房主本机端口加 1。自动房间发现通常不会穿过隧道，直接填写地址加入即可。

房主改变地址时，客机在首页地址框填新地址后点「重连上次房间」。恢复记录会保留原房间令牌；首次加入、重连和观战都可使用域名或带端口的地址。
