# multicolor:arena 1.1

本次按玩家提供的测试表逐项修复，保留既有卡组格式及旧卡牌 ID。版本号、主菜单、关于页和 Windows 文件版本均更新为 1.1。

| 测试表条目 | 1.1 行为 |
| --- | --- |
| 摩多罗·隐岐奈重复 | 组卡器只列出一张；旧版 ID 仍能载入，共用卡名与构筑数量限制。 |
| 「境界」与套牌自机 | 明确显示“返回自机区 / 移除游戏”。选择移除后执行境界的回场；不自动替玩家选择。 |
| 新史「新幻想史-现代史-」 | 费用为 2 蓝 2 红。 |
| 禁弹「Catadioptric」 | 翻倍/减半菜单增加“停止”；选目标时右键返回该菜单，无目标也能退出。人机没有适当复制目标时停止。 |
| 旧史「旧秘境史-古代史-」 | 本体结算后移除，不能通过当回合其他除外使用许可再次使用本体；正常授予其他符卡的使用许可保留。 |
| 魂魄「幽冥求闻持聪ノ法」 | 费用为 2 绿 2 黑 1 黄。 |
| 川雾的引航人「小野塚小町」 | 按原尺寸截图的“2血3灵力值”，保留攻击力 4，改为 4 / 2、灵力 3。 |
| 半灵与幽冥求闻持聪之法 | 结束阶段不能牺牲受保护的半灵，包括作为慧音等异能的费用；主要阶段仍可牺牲。 |
| 神隐的主犯「八云紫」 | 套牌自机的延迟回场被反制或无法进场时，重新询问是否回自机区。拒绝时保留原除外对象、指示物和区域身份。 |
| 妖怪之山的哨戒「犬走椛」 | 下个结束阶段检查登记的椛是否仍为场上的同一对象；已离场、离场后重新进场或更换操控者不会沿用旧监视。 |

| 「百万鬼夜行」特殊指示物 | 普通、醉醺醺、狂气的 +1/+1/+1 指示物全部计数并移除，放回时统一为普通指示物，不继承附加能力。 |
| 「天界ノ蜜桃」 | 翻倍包括醉醺醺、狂气在内的所有已登记指示物，保留各类型及其效果。 |
| 引雷的亡灵「苏我屠自古」 | 贫乏指示物改为累加 1，不覆盖原数量。 |

巡礼的专项测试使用数据库中的真实时符和乐章逐张执行改写与结算，不再通过临时改卡牌类型来替代实际数据。另覆盖禁弹正常连续复制、没有目标退出、自机返回选择的保存恢复，以及半灵保护的阶段边界。

测试脚本：`tests/test_v11_bugs.gd`、`tests/test_v11_ui.gd`。既有回归包括全卡池触发/启动审计、指示物与伤害规则、实际 ENet 回环自组卡组开局、BO3、悔棋、观战及回放。最终结果和发行校验记录见 `work/v11/validation.json`。

发行包包含 EXE、PCK、511 条卡牌记录及所需卡图、四套内置卡组。首次启动会在 EXE 同级创建 `deck` 和 `replay`。不会打包开发者的联机身份、未结束对局或个人回放。新卡裁剪图所依赖的原图资源也随包导出。

请双方及观众使用相同的 1.1 完整包。旧版 `.mdeck` 可继续导入；旧版未结束对局和 `.mreply` 仍受规则版本校验。ZIP 旁提供传输校验工具，解压后提供 EXE/PCK 校验工具。本机回环和本地复制验证不等同于真实双机、异地网络或 U 盘硬件测试。
