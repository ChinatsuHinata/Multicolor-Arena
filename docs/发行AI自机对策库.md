# 发行 AI 自机对策库

发行人机的蕾米速攻策略复用实验模型的 `scripts/ai/matchup.gd` 分类入口，按己方自机和对方完整自机组合选择手写对策。运行入口为 `scripts/ai/release_counterplay.gd`，条目在 `data/release_counterplay.json`。目前有 59 个单自机条目（包含二重身）及堇子＋二重身的独立组合条目；各版本分别保留身份和规则说明。

这份库是人工策略，不是训练权重。默认人机直接调用，不需要打开试验 AI，也不读取 `work/ai-training/`。Windows 的现有 `data/*.json` 导出规则会包含它；试验模型仍按发布规则排除。

## 分类与回退

对策限定己方小蕾米 `74`。复制、妖精居所变形、异画、区域和控制权变化沿用注册自机的原身份。双自机按排序后的完整组合匹配，不套用其中一个单自机的条目。对方新自机、身份未知、未收录组合、无效条目或库缺失时，回退通用蕾米策略；其他己方自机不借用这份对策。

每个条目写有 `label`、`plan` 和实际使用的 `policy`。决策在 `ai_memory[seat].counterplay_routing` 记录识别结果、匹配条目、回退原因和参数，供对局保存、恢复与调试追查。分类只读取公开注册自机，风险判断只读取公开资源、战场、手牌数量和仍有效的明牌记忆。

## 执行规则

| 参数／规则 | 运行行为 |
| --- | --- |
| `target_bonus` | 提高公开在场的注册核心的解场、神枪目标和凭依解牌价值；仍核对实际剩余血量、防伤、目标和支付。灵梦原有神枪最高优先级保留。 |
| `night_bonus` | 核心公开在场且能力未被锁定时，提高夜王封锁触发／启动的规划价值；已被夜王封锁时不重复加分。 |
| `castle_bonus`、`queen_bonus` | 六资源起，红魔馆须有至少两个就绪攻击者且超过实际预计阻挡者；四蝙蝠须合法、可支付、有四个空格和光环来源。满足这些条件才加分。 |
| `life_loss_threshold` | 针对不灭、防避、吸血等核心，在其公开在场时将极光非斩杀压血的生命门槛从 12 提高至最多 15；墓地蕾米的恢复策略仍保留。 |
| `reimu_seal` | 两个灵梦版本启用下述专用开场、留费风险和凭依夜王规则。 |
| `reimu_probe` | 两个灵梦版本启用神枪补刀限制及小单位试探；所有默认搜索与执行路径共用限制，试验策略也过滤不满足补刀条件的神枪目标。 |
| `support_targets` | 可选的卡牌ID到优先度映射（0～2000），将已复盘的普通支援单位纳入高价值解场候选。仅按完整对局分类、敌方实际在场单位生效；仍检查击杀、支付和预留。不根据此字段猜测隐藏手牌。 |

各条目的说明还列出该自机的核心机制和现有通用策略应注意的条件。说明中的未知响应、未来抽牌或随机结果不会成为已知输入；优先度和预测不等于保证击杀或保证胜利。

## 灵梦专用对策

主要阶段在使用缓存路线、斩杀搜索和展开规划之前，先尝试神枪、雾川、秋意之溪等有效的非不夜城解法；神枪不能被对手响应，适合关闭梦想封印的角色约束。缺少蕾米角色来源且组合费用允许时，先建立蕾米，再处理灵梦；薄场还可比较极光牺牲。解牌须能合法命中并达到实际击杀条件。

不夜城已移出灵梦的优先开场解牌列表。先验证玩家斩杀，再与本体共用小单位吸血判断：小蕾米在场、不夜城当前可支付，且模拟进攻能实际增加本回合回血并保留不夜城费用时，优先出动低价值小单位。战斗后重新核对核心剩余血量、防伤和真实回血；达到击杀线便允许不夜城及时解核心，不再继续牺牲小单位。基础三伤的不夜城解灵梦后于普通展开，不能因为对策库的目标加分就抢先消耗。普通出牌及灌伤规划也等待这一步；完整验证的斩杀仍可先用不夜城解必需的阻挡者。

例如六血灵梦阻挡一攻小单位并使其死亡：灵梦实际剩五血，己方吸血一次，不夜城只有四伤，仍不足以解场。灵梦阻挡后横置，第二个小单位打玩家再吸血一次，不夜城达到五伤后才解灵梦；不会把第二次未阻挡攻击算成灵梦额外受伤，也不会为了继续吸血送掉第三个小单位。

神枪不直接攻击当前剩余血量超过四的灵梦；剩余血量按当前实际血量减去已受伤害计算，并继续核对防避、防伤与不会被消灭。无法有效直接解场时，先让能合法进攻、费用不超过三的非蕾米小单位试探，优先低价值单位。灵梦实际阻挡并受伤后，重新检查神枪能否补刀；不阻挡则继续小单位压血，不把预计战斗伤害当作已经发生。没有合法小单位时保留神枪，不能强行空耗。只剩横置或不能参与战斗的灵梦时，不再为了试探而牺牲小单位。

夜王强化实际生效且对方处于本回合封锁时，蕾米可以与灵梦或核心自机交换。直接进攻前会检查所有合法阻挡组合：任何能杀死蕾米的组合，都必须实际损失至少一个灵梦或在场能力核心；若对手仍可选择只牺牲普通单位、保住核心而杀死蕾米，则不认可直接交换。联合阻挡的战斗伤害优先分配给能被击杀的核心，防避、先制和不会被消灭仍参与模拟。有小单位时也可先试探，再根据实际阻挡决定蕾米进攻。没有夜王强化、封锁已过期或核心无法击杀时，保持原有蕾米保护规则。

灵梦仍在场、对方有未知手牌或记住的梦想封印「瞬」，且公开资源能支付其实际费用（通常两黄）时，暂缓直接使用费用至少四的展开牌。雾川等有效四费解场不受阻止；神枪和夜王的不可响应施放也允许通过。正常出牌、搜索执行与缓存路线共用这个限制。对方没有手牌、所有手牌已知且没有封印、费用不足、灵梦离场或已被夜王封锁时解除限制。不会把任意两种颜色误认成两黄。

此公开角色窗口也适用于大帕等其他卡组中的普通灵梦；原始自机分类保持不变。普通灵梦在场时复用非不夜城解场、封印留费和夜王窗口判断，不把它误记为对方的注册自机，也不凭自机分类假定手牌中一定有封印。

凭依不再先假定对方不反制而搜索直伤斩杀。可合法解灵梦时优先取回神枪；否则有可支付夜王和在场蕾米时提高夜王的取回价值。完成凭依交换后，若存在封印风险或对方仍有至少四个公开可用费用来源，在凭依阶段的高速窗口使用夜王指向蕾米。没有合法蕾米目标或费用不足时不空用；封锁已经生效时不重复施放。

## 系缚阵与秋意之溪

玩家所称的“系紧阵”对应卡牌 `field-rei-005`，当前名称为“系缚阵”。若非蕾米友军已横置、仍被有效在场的系缚阵锁住，且对方有剩余血量四或五、能被秋意之溪实际五点伤害击杀的核心，主要阶段在规划前优先用秋意之溪牺牲该友军。这个规则适用于各类对手，不只灵梦。

牺牲不会选择小蕾米或大蕾米。锁定来源离场／失效、牺牲不合法、目标受防伤无法击杀、费用不足或目标不合法时，不触发这项优先规则；仍使用其他现有走法。凭依也提高能完成这项处理的秋意之溪价值。

## 凭依与结晶

前五资源的普通凭依会保护手中最后一张宵暗之翼、莉莉黑、吸血鬼妖精、键山雏和红魔馆，不能仅因另一张牌评分更高便将它换入颜色盘。重复牌可交换；公开、可支付的解场、蕾米恢复或灵梦窗口中的夜王可构成例外，完整引擎验证的即时斩杀也可使用展开牌完成交换。六资源起仍允许把低即时伤害的宵暗之翼换成有效压血牌。

凭依评分在私有副本中校正交换后的手牌、颜色盘区域，并按下一主阶段的真实使用规则检查战场颜色、角色、计时、同称号、格数、费用和目标。空场时封兽与大蕾米都可能无法登场；此时应取回妖精、宵暗之翼、莉莉黑或红魔馆等合法颜色来源。只付得起费用不再获得可登场高费牌的分数。所有检查保持实际战场、随机状态和隐藏手牌不变。

结晶优先普通低价值候选；只有手牌或颜色盘有天狗文，且手牌与颜色盘中有同名多余大单位时，才允许结晶多余副本。保留最后一张大蕾米和天火人；极光、不夜城和基础伤害符卡排除在候选外。`tests/test_remilia_resource_ai.gd` 验证实际凭依、例外及结晶规则。

## 死亡清场与保命阻挡

普通神枪、雾川、秋意之溪和不夜城针对带有 `death_six` 的单位（灵乌路空）时，在副本上真实结算解牌及后续触发，并比较双方失去的单位费用、灵力和注册自机价值。己方损失更大时拒绝普通解法；夜王已实际封锁亡语、清场交换有利或完整验证的即时斩杀仍可执行。该规则不限制普通目标，也不凭录像未来发生的复活预测当前对局。

通常仍只做能击杀攻击者且阻挡者全部存活的有利阻挡。当当前不阻挡将被灵力伤害击败，或会收到大町给予的第三枚铜钱时，允许牺牲低价值单位保命。候选用真实战斗规则验证，包含先制、负指示物、歼灭、伤害防止和死亡触发；不会把仍然致败的垫刀报告为成功救场。没有救场路线时仍履行卡牌要求的强制阻挡。
