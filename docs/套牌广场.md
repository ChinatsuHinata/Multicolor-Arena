# 套牌广场

套牌编辑器的桌面、安卓界面均提供「套牌广场」和「上传套牌」。两者都需要有效的玩家登录；未登录或云端凭据失效时进入登录页面，登录成功后继续原操作，编辑中的未保存草稿保留。

上传当前套牌时填写标题（1–40 字）、描述（最多 2000 字）和标签（最多十个，每个最多 20 字，用中文逗号 `，` 分隔）。上传使用当前草稿的快照，保留主副卡牌顺序、规则集和异画编号。云端自行校验登录凭据并记录上传者账号、昵称；拒绝伪造上传者、图片、资产字段和任意资源路径。

广场按最近上传顺序平铺展示。桌面每页六副套牌，宽度不足时减少列数；安卓每页只显示一行，按可用宽度显示一至三副，通过「上一页／下一页」查看更多套牌，无需滚动。安卓卡图随可用高度缩放；高度较少或展开颜色筛选时改为卡图与信息左右排列，长标题和标签单行省略，完整内容在详情查看。「我的上传」中的编辑和删除操作在套牌详情中提供。安卓分页使用云端原有六副套牌批次，无需更新服务端；页码按实际显示数量计算，刷新保留当前行。自机图从访问者本地卡图库按上传代码中的异画编号读取。详情显示标题、上传者、描述和标签。「下载套牌到本地」保存一份带新本地 ID 的 `.mdeck`，在编辑器下拉列表中选择使用，不替换当前草稿。客户端无法识别代码中的卡牌或异画时提示更新并禁止下载。

搜索条件可组合自机名称／别名、标签和套牌颜色，并作用于整个云端列表后再分页。标签搜索支持中文逗号 `，` 和英文逗号 `,` 分隔，例如 `灵梦，速攻` 只显示同时匹配两个标签关键词的套牌；忽略空项、首尾空格和重复项。颜色取自机、主卡组和副卡组所有出现颜色的并集，排除莉莉白、贤者之石及所有带「极彩」关键词的牌（包括同卡异版）。文字命令 `红蓝` 筛选同时包含红、蓝的套牌，`红` 筛选包含红色的套牌；已移除单色限定命令。点击色块筛选包含全部选中颜色的套牌。色块使用正常按钮／触控高度，筛选说明单独显示在下一行。安卓将三个搜索框及操作按钮合为一行，套牌数量与加载提示放到标题旁。颜色按钮和说明默认折叠，点「颜色筛选」展开；收起后仍保留筛选条件，按钮显示已选颜色数量。展开、收起均保留未提交的输入。

「我的上传」切换为当前玩家上传的套牌列表。列表或详情中的「进入编辑器」加载云端卡牌、顺序及异画到现有组卡器；若当前草稿未保存，先使用组卡器原有确认流程。修改卡牌后点击「更新套牌」，可修改原标题、描述和标签，并保存到同一条云端记录。普通「保存」仍保存本地卡组。「删除」经界面确认后删除自己的云端记录。每次编辑、删除都在服务端校验记录所属玩家，他人无法通过伪造界面状态执行操作。

## 云端

`relay/account_store.py` 复用原玩家 SQLite 数据库，新增 `deck_posts` 表。表中仅保存标题、描述、标签、标准卡组代码、上传者信息、编号和时间，不保存卡图或其他资产。安装采用新增表的迁移，原玩家与会话表保留。

搜索使用由当前卡库生成的 `relay/deck_plaza_catalogue.json`，只含卡牌名称、颜色、别名、编号、可构筑状态和合法异画编号，不含资源路径或资产。更新卡库后运行 `tools/export-deck-plaza-catalogue.gd` 再部署。颜色、自机搜索文本由服务端计算；启动时重算旧记录，避免沿用旧的颜色规则。所属玩家只从有效账号会话取得。

广场请求通过原 WebSocket 入口，使用 `MCP1` 前缀、256 字节 RSA 加密登录凭据及文字 JSON。加密部分含会话、时间、随机数和正文 SHA-256，服务端拒绝过期、重放或正文篡改请求。正文最多 16 KiB；账号服务的 `/deck-plaza` 仅接受回环请求，每次操作均检查有效会话。标准代码的解压长度、字段、张数和编号格式均有限制，响应不包含玩家会话或设备信息。

完整中转部署 `relay/deploy.ps1` 已包含新模块。单独更新广场可运行 `relay/deploy-deck-plaza.ps1`，先在线备份数据库和原程序，检查 Python/Godot 语法，更新账号和中转服务；失败时恢复原程序。SSH 私钥及口令不写入脚本。

## 验证

Python 数据边界：`tests/test_deck_plaza_store.py`。Godot 端到端：`tests/test_deck_plaza.gd`，默认连接本地 `ws://127.0.0.1:47872`，支持 `-- --server <WebSocket地址>`。使用独立数据库启动账号、中转进程后运行；本机入口 `work/run-deck-plaza-tests.ps1` 自动启动和清理测试进程，`-Render` 同时保存桌面与安卓布局预览。测试套牌与本地凭据写入隔离的 `work/deck-plaza-tests/`。

Windows/Android 导出校验同时要求 `deck_plaza.gdc`、`deck_plaza_client.gdc`，并检查两端使用相同数据、规则和版本。
