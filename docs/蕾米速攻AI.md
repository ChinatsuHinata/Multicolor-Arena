## 决策规则

发行 AI 现已接入按双方自机原身份分类的手写对策库，详见 [发行 AI 自机对策库](发行AI自机对策库.md)。灵梦对策在主要阶段规划前优先尝试神枪、雾川、秋意之溪等有效解法，不夜城后移到斩杀检查和小单位吸血之后。在可能的梦想封印两黄窗口暂缓直接高费展开，并在凭依后考虑夜王指向蕾米；雾川等有效四费解场照常使用。系缚阵锁住的非蕾米友军可优先用秋意之溪牺牲，以击杀实际四至五血核心；完整条件和回退见该文档。

## 发行版调用与优先级

默认入口为 `duel_engine.gd` → `remilia_aggro_ai.gd`；`release_counterplay.gd` 读取 `data/release_counterplay.json`，提供公开自机分类、参数和灵梦窗口判断，不另行执行一套出牌 AI。`plan` 是策略说明，真正生效的是 `policy` 与 AI 本体中的相应判断。

主阶段先处理系缚阵牺牲和灵梦的有效非不夜城解法／夜王窗口，再验证即时斩杀。随后处理其他核心和已达到实际击杀线的不夜城，继续小单位试探、恢复自机、组合灌伤、普通展开和进攻，最后考虑剩余解场。不夜城基础三伤解灵梦不抢普通展开；小单位吸血后达到核心击杀线时则及时收尾。实际阻挡、回血、资源或防伤变化都会重新判定。

普通出牌和持续灌伤共用吸血铺垫判断；斩杀搜索优先尝试小单位吸血，同时保留先用不夜城解阻挡者才能赢的路线。只有完整规则模拟验证的斩杀可以跳过普通灌伤的等待。试验 AI 仍是单独启用的入口，不替代发行策略。

| 四费 | 已证明的即时斩杀、核心支援或阻挡威胁解场保留原优先级；其余情况下，小蕾米自机在场时优先使用键山雏建立保护，之后继续封兽、红魔馆及其他单位的原有展开顺序。四费指颜色盘达到四张的回合，雏本身费用仍为一红一黑。 |
| 键山雏保护 | 对方符卡或单位能力指定己方小蕾米自机时，使用当前合法的雏改目标选项，支付两点生命把该目标转给雏；检查区域、能力禁止、目标合法性和实际费用。同一目标槽已有未结算的改目标能力时不重复支付，不干预己方符卡或针对普通友军的操作；剩余生命不超过两点时不发动，避免为保护单位直接输掉对局。 |
| 结晶 | 优先选择普通低价值候选，降低大单位结晶权重。只有手牌或颜色盘中有小文文（天狗文），且手牌与颜色盘合计存在至少两张同名大单位时，才允许结晶其中的多余副本；分别保留最后一张大蕾米和天火人血枪，维持六费、七费登场或凭依取回的可能。大单位之间按灵力与费用选择；场上或墓地的小文文不满足条件。自机本体、极光、不夜城和基础伤害符卡不作为结晶目标，没有可牺牲候选时放弃可选结晶。 |
| 蕾米死亡 | 没有墓地移除威胁时，有极光且对方不能支付双蓝／双绿及已知合法反制，可进坟等待下一己方回合复活；也可持天狗文，在下一回合能支付文＋小蕾米总计七费时进坟，或三费死亡、四费全费使用文回手、五费重拍。三费死亡进坟后，下一回合能合法使用极光时仍优先极光直接复活，文作为备选。文回手时拒绝再次返回自机区，保留手牌中的实际自机。六费起持极光时，先检查返回自机区后的本回合合法斩杀，再比较下个己方回合的极光直伤与四蝙蝠输出、进坟后的复活输出。极光能单张或连续斩杀，或自机区支援四蝙蝠的路线伤害更高时返回自机区；复活能支付且蕾米光环产生更高输出时仍进坟。预测只使用已有公开颜色和手牌，核对复活加四蝙蝠的实际组合费用、角色约束、四个战场格、阻挡与已知响应。否则返回自机区等待计时。已知极光反制核对实际费用、角色约束与堆叠目标。 |
| 文与墓地移除 | 对方有可合法牺牲的富士见之女、可发动的四季映姬等墓地移除能力时，不使用文，蕾米也不为文或极光进入墓地；判定包含能力禁止、横置、召唤失调和响应限制。己方回合死亡时还考虑四季在下一对方回合重置，以及死亡吞噬触发。文优先伤害对方玩家，先保证即时斩杀，再回收墓地蕾米，否则选最高灵力单位；空墓地不空拍文。 |
| 中盘解场 | 目标包含优势阻挡者、能够联合杀死蕾米的阻挡者，以及有自机能力、较高费用或较高战斗数值的单位。按自机能力、光环覆盖、全队吸血、费用与战斗数值排序；横置的对方自机也会处理，无可攻击单位时仍可主动拆核心。先考虑价值最高的目标，同一目标优先能击杀的冈格尼尔，其次雾川、秋意之溪、不夜城；会核对伤害防止、剩余血量、合法目标和支付能力。秋意之溪在宽场牺牲低价值单位；窄场也可牺牲被持续锁住或低价值的单位来移除灵梦等核心引擎，避免牺牲己方蕾米。 |
| 神枪目标优先度 | 四血灵梦保留最高优先级；幽幽子、上白泽慧音等剩余血量至多四、拥有已启用自机能力或独立启动能力的自机，优先于云山与普通阻挡者处理，横置时也会处理。此类核心纳入公开登场预测、预留神枪费用、高速解场和斩杀搜索排序；普通副本仍可按独立启动能力识别。蕾米尚未在场、已结束计时且能合法登场时，核对并预留蕾米加神枪的组合费用，先登场蕾米再用神枪，避免先花四费雾川使角色约束继续停摆。己方单位正面临死亡时仍允许用神枪紧急救场。所有目标都必须能被实际伤害击杀，并核对合法目标与伤害防止，不会把受保护或剩余五血的核心视为可击杀。 |
| 神枪等待与补刀 | 对方有五、六血或更高有效血量的单位时，血量计算包含当前伤害及叠加防避；先保留神枪和可支付的一红一黑，让安全进攻发生。阻挡宣告后先等战斗伤害，实际剩余血量和防避进入四点可击杀范围时，在伤害后的高速窗口补刀；仍无法击杀就继续等机会。攻击者已死亡但对方阻挡者仍在场时也可补刀。普通战斗本来就能杀死的小阻挡者不会提前消耗神枪。 |
| 神枪跨回合预留 | 依据对方公开自机、记住的明牌单位及堆叠上已宣告的单位，判断对方回合可合法登场且能被神枪击杀的高价值目标。优先预留给四血灵梦；四血云山若能额外支付一绿并决斗己方蕾米则提高威胁值，登场后、决斗结算前用神枪拦截。预测核对计时、战场格、称号、战场颜色、重置后已有公开颜色和角色约束，不读取未知手牌或牌库顶；对下一回合可能增长的一张资源按任意颜色的条件情景预留，并核对颜色盘空间与牌库余量，不将可能性当作已知身份或保证登场。仍有高血量补刀或未来高价值目标时，出其他牌也需留下神枪费用；能保证斩杀的路线可以使用这部分颜色。进攻结束后再检查小单位，预留机会消失才考虑释放神枪。 |
| 凭依 | 凭依前先查看手牌与可交换的颜色盘，按潜在伤害动态决定是否搜索斩杀。先模拟不交换，已有斩杀就保留原手牌；否则在共享预算内尝试真实交换，优先从颜色盘取回不夜城、极光、四蝙蝠等能形成斩杀的牌，核对交换后的颜色、区域、入场效果、战场格与已知响应。前期降低未到费用的大蕾米、天火人留手价值，优先将其换进颜色盘取得曲线牌；六费起降低宵暗之翼等不能当回合直接造成伤害的牌的留手价值，提高可支付的不夜城、四蝙蝠与极光价值。有实际可支付的解场机会时保留解牌；神枪补刀及等待高价值单位的预留仍参与评分。开局同色交换优先保留廉价神枪、换下暂时不可支付的天火人；已有较多手牌时降低抽牌符卡留手价值，优先保留可解核心的秋意之溪。 |
| 极光牺牲与直伤 | 对方只有一个高价值单位，或只有两个且两者都高价值、均可牺牲时，优先考虑三费极光牺牲；仍优先使用当前可支付、合法有效且费用不超过三的其他解牌，神枪另核对预留目标。四费雾川不再压过极光牺牲。高价值指颜色值至少四、攻击或剩余血量至少五、灵力至少四，或拥有自机能力的自机；有弱单位可垫牺牲时不将牺牲视为可靠大单位解法。能失去三血直接斩杀时优先直伤，先于夜王组合、红薯登场与铺场；组合斩杀可连续使用多张极光。未立即斩杀时，对手至多十二血，或己方有蕾米且对方无未横置单位时，可以用剩余费用压低生命；已有蕾米在墓地等待复活时保留恢复机会。 |
| 红魔馆优先度 | 手上或颜色盘有四蝙蝠时提高权重；己方有至少两个可攻击单位、数量超过对方当前及明牌可追加的阻挡者时进一步提高，优先增伤后进攻。凭依评分也使用此权重。 |
| 四蝙蝠优先度 | 能合法使用、支付两红两黑并空出四个战场格，且对方至多两个当前及明牌可追加的阻挡者时，场上蕾米光环或红魔馆提高四蝙蝠权重，两者都有时进一步提高。四费也可先于普通铺场使用；高费伤害搜索优先探索这类路线。没有两种增伤来源，或对方阻挡密集时降低权重；最近至多六次阻挡选择中至少有三次记录，且实际阻挡比例达到四分之三时，也降低权重，后续不阻挡会解除旧惩罚。记录随保存、联机及悔棋保留。蕾米在自机区计时期间仍满足支援的角色约束，进坟则需其他合法角色来源。颜色不足、角色缺失或格数不足时不增加权重；真实斩杀仍由完整模拟优先判断。 |
| 明牌追加阻挡 | 记住的境界、毗沙门天寅丸星、诵经的山彦幽谷响子，只有在当前剩余颜色能实际支付、时机和区域合法、未被夜王封锁时才进入模拟。境界可真实闪回至多两个横置单位以恢复阻挡；老虎与高速响子真实登场，核对称号及战场格，并结算防伤、阻挡和响子的死亡伤害。多张响应共享实际颜色，不重复支付。普通非高速响子与未知手牌不被当成这些明牌威胁。此预测同时用于权重、蕾米攻击保护、持续灌伤和斩杀搜索。 |
| 多单位进攻 | 可攻击单位至少比优势阻挡者多两个时，开始从弱到强进攻；后续每次重新检查场面，数量降到优势阻挡者数量时停止亏损进攻。安全攻击仍可进行。 |
| 补牌 | 场上有蕾米、手牌至多两张时优先补牌；手牌较多但不足七张、没有其他有效可支付操作时，也可使用闲置费用抓牌。最多额外抓三张，额外付血后保留至少五血及可见进攻威胁所需的生命，不因补牌超过七张，并检查牌库余量与神枪预留。 |

四蝙蝠符卡创造的疾行蝙蝠会标记来源；只要规则允许宣攻，AI 会在其他非斩杀出牌前逐只派它们攻击，即使对方有阻挡者。宵暗之翼一次创造两只蝙蝠，使用、颜色来源评估和斩杀搜索均要求至少两个空战场格。小蕾米已在墓地且本回合能合法用极光移回战场时，先使用极光复活；战场格不足等情形才考虑极光的其他模式。

## 斩杀搜索

十二血是基础搜索门槛；已有进攻灵力、可支付的不夜城及本回合已获得和潜在吸血生命、极光、夜王会动态提高门槛。有可用四蝙蝠、至少四个空战场格，且场上有红魔馆或启用自机光环的蕾米时，将四只疾行蝙蝠的增伤及吸血计入潜在伤害。凭依前也查看可交换颜色盘中的伤害牌。该门槛只是乐观的搜索上限，不能证明斩杀；每条路线仍须真实支付组合费用并结算合法目标、阻挡、伤害防止、歼灭、吸血、直伤、入场触发和已知响应。路线包含夜王时优先尝试先使用夜王。

对手模拟会优先阻挡当前致命攻击，否则把阻挡单位优先留给剩余可以按保护规则安全攻击的高灵力攻击者；不会为禁止进攻的蕾米预留阻挡。对手使用已公开获取、仍持有且能合法支付的反制及战斗响应。不会读取未知手牌身份或双方未公开的牌库顺序；路线表示在已知响应下的斩杀机会。实际阻挡、响应、剩余颜色或已知手牌改变后，会丢弃失效路线并重新计算。

极光能直接斩杀时，先用真实规则验证单张直伤是否能在已知反制下获胜；清除单独大单位的牺牲模式也参加斩杀搜索。蕾米复活能为至少四个可攻击黑色单位增加灵力时，提前尝试这条路线，避免有界搜索耗在攻击排列上。能立即影响进攻的光环、疾行或入场效果复活参与正常搜索，其他复活放在现有单位攻击之后。找到斩杀路线后，逐一跳过每个动作重新结算费用、攻击与响应；仍能获胜时删除该动作，并更新后续场面记录。多余宵暗之翼、铺场及复活都可删除，必要的蕾米光环、疾行复活、入场效果或角色符启用仍可保留。

搜索按等价局面去重，每次最多探索 1800 个节点、650 毫秒；有夜王时额外先进行至多 325 毫秒的夜王路线搜索。入场触发的目标按该卡组策略选择，复杂局面受搜索预算限制。

高费灌伤规划另有 350 毫秒候选搜索预算，优先验证红魔馆＋四蝙蝠组合，再搜索最多三层出牌、每层保留四条路线，并按实际规则继续安全进攻和使用直伤。超过十二血的四蝙蝠／不夜城斩杀先验证这些灌伤路线，再进行常规斩杀搜索；只接受本回合已经获胜的完整路线，下轮伤害预测不作为斩杀依据。凭依候选仍受共享期限和每次交换的 150 毫秒期限约束。单次路线结算与下一轮评分有额外开销。

凭依前的原手牌与交换路线共用 1300 毫秒搜索预算，单次交换路线最多分配 150 毫秒；模拟交换、评分和路线精简另有少量开销。超出预算时返回普通凭依评分，不把未探索分支当成已证明的斩杀。
