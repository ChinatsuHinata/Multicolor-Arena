# multicolor:arena 版本记录修复工具

用于误装较高版本、安装版本记录异常，导致完整安装包拒绝重新安装的情况。

## 给玩家使用

1. 关闭游戏和安装器，在平时玩游戏的 Windows 账户中双击 `MulticolorArena-VersionRepair.exe`。无需管理员权限。
2. 点击 **清除版本记录**，确认后等待“修复完成”。原版本记录会先备份。
3. 运行与本工具配套的新版**完整安装包**，确认原游戏目录后重新安装。

工具仅清除当前账户的本游戏安装记录中的 `DisplayVersion`，并写入修复标记。不会删除游戏文件、安装路径、卸载程序、快捷方式、卡组、回放或设置。32 位和 64 位注册表视图都会检查；没有安装记录时不创建记录。便携 ZIP 版不需要本工具。

**必须使用已支持修复标记的完整安装包。此前发布的安装包仍会因版本号缺失而拒绝安装；差分补丁要求原版本和原文件完全匹配，不能用于此操作。** 清除版本记录不会改变游戏本体的版本，也不会修复缺失或损坏的游戏文件；重新安装完整包才会替换程序文件。

如果玩家使用其他 Windows 账户安装了游戏，应切换到当时的账户运行工具。

## 备份与撤销

备份位于 `%LOCALAPPDATA%\MulticolorArena\VersionRepairBackups\<时间-随机编号>\`，可点击 **打开备份目录**。

每份备份包含按注册表视图区分的 `.reg` 文件和 `Restore.cmd`。若清除后决定取消重新安装，在对应备份目录双击 `Restore.cmd`，恢复原版本记录与原修复标记。**重新安装完成后不要恢复旧版本记录**，否则记录会与实际文件不一致。

备份失败时不会开始清除；清除失败时工具会尝试恢复原记录，并显示备份路径。工具仅处理 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\MulticolorArena.Game_is1`，不会扫描或修改其他软件。

## 开发者构建

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\build-version-repair.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\test-version-repair.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\test-version-repair-installer.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\build-installer.ps1 -SkipExport
```

修复工具输出至 `builds/repair-tools/`，使用 Windows 自带的 .NET Framework 4 编译器，无需下载依赖。完整安装包使用更新后的 `installer/MulticolorArena.iss`；`-SkipExport` 要求当前版本的 EXE/PCK 已位于 `builds/installer-staging/<版本>/`。

完整安装器只在版本号缺失且 `MulticolorArenaVersionReset` 字符串为 `1` 时允许重新安装。正常安装记录仍执行原有的版本比较；安装成功后删除修复标记，恢复正常更新限制。
