安装：
1. 将整个 testmod 文件夹放在任意可读取的独立目录中，不需要改动或重新打包游戏 PCK。
2. 游戏中打开 设置 → 模组 → 添加模组目录，选择含 manifest.json 的目录。
3. 勾选 testmod，点击 应用选择。卡组编辑中选择“模组”规则集后即可使用这些牌。
4. 组卡与创建房间时选择“模组”规则集，赛制可选 BO1、BO1 换备牌或 BO3。对手及观众需要启用相同模组；不同路径可以使用，但包集合、版本、API版本、全部文件内容必须一致。

更新文件后请在未加入房间时重新应用选择。加载时会固定脚本和卡牌定义，避免对局中读取变化的JSON。
此包是可信GDScript扩展，不是安全沙箱。
本版附带24张可构筑牌的完整卡面（art/），使用imagegen生成的独立插画和用户提供PSD中的六边形颜色值、纹样。蝙蝠衍生物沿用原版蝙蝠图片；红绿御柱沿用原版御柱衍生物卡图；御制棒正文中的三维数值按「宵暗ノ翼」以攻防胶囊和灵力印章呈现。
符卡和结界为2079×1488横版；自机、单位、道具为1488×2079竖版适配。
卡名、费用、三维属性、牌文来自原JSON；1.0.5使用教学PSD与原版圣白莲对照校准标题、字距和X费用字体；三维属性变化采用攻防胶囊与灵力升降印章。
单位正文已避开上方分割花纹；竖排关键词下划线位于文字左侧。
卡图采用模组内相对路径，需要游戏支持外部模组相对图片路径及原生PNG加载（本次配套源码已加入）。旧客户端请先更新游戏。
插画标注AI生成，不沿用PSD样张中的原插画作者署名。

牌文约定：
- 无前缀卡名统一加日文书名号「」，编辑器中的の统一显示为ノ。
- 两种棒进场时先抓一张牌，再移除牌库顶两张牌；不再拥有空牌库替代抓牌能力。
- 核燃料棒从牌库移除时由操控者选择目标单位；御制棒创造红绿双色3/3/2御柱，不附加英勇或不占战场格。
- 融合炉进场可选至多两张自己拥有的移除区棒洗回牌库；仅从牌库移除触发结算时可选择立即免费使用，不能任意从移除区使用。
- “「人里的参拜者」”只有姓名、没有称号，可在战场格数允许时同时操控多个。
- 未命名的1绿X黄X黑时符暂名“魔力共鸣”；X黄和X黑分别支付同一个X数值。
- “超人「圣白莲」”的指示物按用户确认增加攻击力、血量、灵力三项。
- 圣白莲先按声明X支付，再选择是否加倍X；放弃加倍仍消耗本回合第一张X牌的机会，使用触发及结算看到选择后的X。
- 圣白莲保留英勇；对手使用符卡、启动或触发能力指定她时须额外支付任意两点颜色值。
- 核热的循环的两次“可以”独立选择；可以不移除牌库顶牌而选择回收除外的角色符卡。
- 十凶星不足10张时尽量执行：先选至多2张入手，再选至多2张横置放入颜色盘，其余除外。
- 魔人经卷按每个能力实例每回合一次，在生成触发时占用次数，反制后不恢复次数。
