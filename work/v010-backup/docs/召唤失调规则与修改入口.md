整理日期：2026-09-18，项目版本 v0.9.3。本轮仅调取与整理，未修改召唤失调判定。

> 2.21.若一个单位想要进行攻击或者起动含有“横置该单位”字样的能力时，除非该单位的操控者在上一个重置阶段前操控它，否则将不能攻击或者起动含有“横置该单位”字样的能力。

> 5.5.1 凭依阶段之后将进入主要阶段。在主要阶段中，只要对抗为空，且不在战斗中，主玩家在拥有执行权时可以选择使用一张手牌；或者选择一个由其操控，且并非本回合才开始操控的未横置单位（除非其具有疾行）攻击。

> 5.5.2a 对手可以选择横置它任意数量的竖置单位来阻挡你正在攻击的单位。当然玩家也可以选择不进行阻挡。

> 疾行：具有疾行的单位可以在进入战场的回合进行攻击。

## 当前游戏的实际处理

| 动作或情况 | 当前处理 | 依据或实现说明 |
| --- | --- | --- |
| 本回合新进场单位攻击 | 通常不能 | 单位节2.21、5.5.1 |
| 新单位具有疾行 | 可以攻击，但仍需竖置、合法时机等 | 5.5.1及牌表疾行词条 |
| 新单位启动以“横置该单位”为条件的能力 | 不能；当前疾行也不免除此限制 | 单位节2.21；疾行原文仅提攻击 |
| 新单位阻挡 | 可以，只要竖置并符合其他阻挡限制 | 5.5.2a没有排除新进场单位 |
| 新单位发动无需横置的能力 | 不因召唤失调被禁止，仍需满足能力条件 | 当前通用启动检查与扩展能力检查 |
| 进场、死亡等触发能力；持续能力 | 不因召唤失调失效 | 它们不是宣攻或横置该单位的启动 |
| 新进场道具、颜色盘的牌 | 不套用单位的召唤失调限制 | 只判断战场上的单位 |
| 对手回合到来 | 不提前解除己方新单位的限制 | 当前实现按操控者自己的回合计数 |
| 到自己的下一次重置 | 解除原来的进场限制 | 自己的回合计数增加 |
| 从墓地、除外区等重新进场 | 重新记录进场时刻，再受限制 | 区域版本更新；疾行例外照常 |

例：你本回合召唤一个普通单位，本回合不能用它攻击；对手回合可以用竖置的它阻挡；到你的下一回合重置后才可正常宣攻。桑尼给予的“本回合疾行”能让目标当回合攻击，但当前不会解锁其需要横置的启动能力。

## 代码入口

- [enter_field](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:294)：记录 entered_turns、进入战场并触发进场事件。
- [summoning_sick](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:680)：只判断战场单位，比较该单位进入时与其操控者当前的回合计数。
- [start_turn](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:85)：增加该玩家回合计数并重置牌。
- [can_attack](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:430)：宣攻约束；疾行仅在此放宽召唤失调。
- [activation_error](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:692)：通用启动能力含横置条件时检查召唤失调。
- [extension_activation_error](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:865)：已登记扩展启动能力的横置限制。
- [legal_blockers](C:/Users/tzx20/Documents/test/scripts/rules/duel_engine.gd:438)：阻挡合法性，不检查召唤失调。

v0.9.4 使用 [summoning_mist.gdshader](C:/Users/tzx20/Documents/test/assets/summoning_mist.gdshader) 在场上单位外围绘制持续流动的淡蓝色雾环，完全无文字；在状态解除后移除。它独立于蓝色可交互边框与黄色选中边框。疾行例外只放宽攻击，故疾行单位仍可能有雾环。堆叠中的异能来源副本不显示雾环。

## 后续修改时需要明确的范围

1. 若只希望新单位可以攻击，修改 `can_attack` 的例外即可；不要顺带解除横置启动能力限制。
2. 若疾行也要允许横置启动能力，需要同步修改 `activation_error` 和相关扩展能力检查，并补充该规则裁定。
3. 若新单位也不能阻挡，需要明确改变5.5.2a的当前解释并修改 `legal_blockers`。
4. 目前模型主要记录进场时刻，尚无通用“控制权变更”系统；将来加入夺取控制权时，需要额外记录开始操控的时刻，不能只看进场时间。

现有检查入口：`tests/test_v06.gd` 验证经过对手回合仍不提前解除、自己重置后解除；`tests/test_v081.gd` 验证刚进场竖置单位仍可阻挡。本轮交互调整不改变这些规则。
