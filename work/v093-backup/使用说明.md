# 极彩 Multicolour · v0.9.2

在 Godot 中运行 `main.tscn`。窗口为 1600×900，并默认最大化。

## 开始测试对局

1. 主菜单进入「人机对战」，点击「载入测试卡组」。
2. 双方会选中各一套 50 张测试卡组，并启用「不检查卡组」「人机必定投 1」。可自行换卡组或选先后手。
3. 点击「开始对战」，完成先后手选择。起手 4 张，点选想换的牌后「调度」，或直接「保留」。
4. 正常对局会在生命归零、抓空牌库或投降时结束，之后可返回准备页。

测试卡组只使用原来的 8 种卡，含重复牌及所选自机同名牌，所以需使用「不检查卡组」。载入按钮不会立即写入卡组文件，也不会覆盖已有卡组；在组卡器主动保存时才会写入当前列表。

组卡器已开放61种卡。可按类别、完整名称或严格颜色组合检索卡牌并加入自己的卡组。现有卡池已能构建满足50张、同名最多4张的合法卡组。

## 对战操作

- **凭依**：可选的竖置调色盘牌显示蓝边。点击一张变为黄边，再次点击取消；随后点击一张手牌（黄边），最后点击「确定凭依」才交换。手牌也可再次点击取消选择，或直接「跳过凭依」。
- **出牌**：按住手牌拖动，在底部手牌区外松开，随后选择目标和支付。拖回手牌区松开即可取消；单击可用手牌只切换黄边选中状态，不会施放。左侧自机仍可点击使用。符卡目标可为单位、玩家生命按钮或右侧堆叠中的合法目标牌。
- **自动支付**：默认开启。符卡只有一种合法付费方案时直接支付；存在选择时弹出「自动支付 / 手动选择 / 取消使用」。其他牌按设置直接自动付费或手选。自动选择优先使用道具、单色资源，保留双色资源和一次性红薯。
- **手动支付**：点颜色盘、可产色的道具或红薯。双色且两色都需要时选择颜色；再次点已选资源可撤回。费用选齐后点「确认支付」。确认前可随时「取消使用」，不会扣费、出牌或让人机响应。
- **红薯**：仅后手初始持有，在颜色盘旁显示；不计入颜色盘数量。支付任意一种颜色的 1 点，实际支付后消失。
- **攻击与异能**：单位只有「攻击」一种可用行动时，点击先以金边和剑标记预选，左下角出现「攻击」。点「攻击」才宣告，右键其他位置取消；同时可以攻击和发动异能时，弹出行动卡面供选择。右键其他区域关闭选择。进场单位不再显示召唤失调文字，但仍需到操控者下一回合重置后才能攻击；疾行按原规则允许当回合攻击。
- **阻挡与伤害**：攻击响应结束后，没有合法阻挡单位会自动继续，不显示阻挡询问；有合法单位时点选再确认，也可不阻挡。进攻方分配多个阻挡者的伤害时，显示前 n−1 个阻挡者的无边框卡面，用下方「− / +」分配；最后一个自动承受剩余伤害。单位之间按攻击力结算，未被阻挡时按灵力伤害玩家。
- **观察战场**：支付、目标、异能、调度、凭依、阻挡、伤害分配等选择期间，右上角可点击「观察战场」暂时收起选择界面。可右键看牌、查看墓地或缩放；再点「返回选择」恢复原界面，已选费用、目标和伤害数字均保留，观察期间不会推进人机或提交行动。
- **高速与反制**：拥有执行权时将高速符卡拖出手牌区，再点堆叠中的目标牌。双方让过后只结算最上面一个对象，之后重新开放响应。
- **响应模式**：点击左上按钮，按「默认 → 开 → 关 → 默认」循环切换，新对局为「默认」。「开」在每个合法响应窗口都询问，无论有没有可响应的牌或异能；「默认」只有存在合法响应动作时询问，否则自动让过；「关」始终自动让过，即使有可用牌或异能。响应关闭时不点亮响应候选，也不能抢在自动让过前手动出响应牌。正常主要阶段出牌、阻挡、凭依、调度等选择不受影响。响应目标/付款尚未提交时切到「关」，取消本地预选并返还预留费用，不产生公开动作。
- **回合推进**：点「结束主要阶段」；进入结束阶段等阶段时，屏幕中央以无边框文字短暂显示名称。英勇、计时、弃牌和其他必要选择处理完成后换人。
- **设置与投降**：右上角「设置」中可开关自动支付、继续游戏或投降；投降再次确认后结束。
- **查看卡片**：右键手牌、战场、自机、颜色盘、墓地顶牌或堆叠，左侧显示大图、完整卡名和可滚动原牌文；关键词不附加解释，无能力牌留空。对手手牌与牌库只显示牌背和数量，隐藏信息不会泄露。
- **查看牌堆**：点击双方牌库、墓地或除外区，右侧按牌堆从顶到底显示纵向卡片列表，滚轮上下翻看，点「×」关闭。普通模式下双方牌库一律显示卡背，右键也不公开牌名；调试模式下可查看牌面。墓地与除外区可右键查看完整牌文，己方墓地中当前可发动的卡显示「发动」。列表外的桌面滚轮用于缩放。
- **场面标识**：当前可以交互的手牌、单位和选择候选显示蓝边，选中显示黄边；卡牌及异能副本进入堆叠后不显示选中边框或外发光。颜色和费用直接看原卡面。单位底部显示攻击力 / 剩余血量 · 灵力，各数值高于原值为绿色、低于原值为红色，相同为白色。横置的永久物和颜色盘变暗，重置后恢复。
- **战斗动画**：攻击者显示剑、阻挡者显示盾。伤判时双方单位碰撞，多阻挡逐一展示；没有阻挡则攻击单位向正前方冲撞。死亡单位在碰撞完成后才显示离场。抽牌、入堆叠、进场、横置等移动动画保留，战场不随阶段重建。

自机单位需要战场永久物提供其全部颜色；颜色盘本身不满足该约束。角色符卡要求战场上有对应角色。灵梦与魔理沙各自的同称号单位不能同时存在。

## 组卡器

左侧预览、中央主副卡与自机、右侧卡库的布局不变。

- 从右侧卡库拖入主卡组、副卡组或自机位来加入；拖回卡库移除；主副卡组之间可移动。
- 单击卡名加入、中央左键复制、右键删除继续可用。
- 支持完整称号搜索、多色筛选、新建、重命名、保存、复制粘贴。顶部「排序卡组」分别整理主卡组和副卡组，按类别、总费用、完整卡名排序，相同牌相邻；张数和自机不变，点击保存后写入。
- 颜色筛选严格匹配整组颜色：选黑色只显示纯黑卡，选红色和黑色只显示红黑双色卡；不包含单红、单黑或其他多色卡。点「全部」或取消所有颜色恢复全部卡牌。
- 右下角「删除卡组」删除当前卡组，确认后同步保存列表；未保存的新卡组只清除草稿。删除最后一副后进入空白卡组。原「备牌」按钮移除，副卡组仍可通过拖放编辑。
- 主卡布局一屏可见50张主卡及1张自机，超过50张继续向下排列并滚动查看，副卡区独立保留。
- 保存要求有自机，容量为主卡 70、副卡 10、自机 1。草稿不用恰好 50 张。
- 正常对战检查主卡 50 张、主卡同名最多 4 张（终言同名最多 1 张）、主副卡不含所选自机同名牌；测试开关跳过这些构筑检查，未知卡、无自机、坏数据和容量上限仍拦截。

## 数据与维护

- `cards/*.json`：61 张卡的中文资料、费用、构筑资格、能力绑定，组卡器和对战共用。
- `scripts/card_database.gd`：卡池登记、字段和能力校验。
- `scripts/rules/duel_engine.gd`：回合、支付、区域、堆叠、战斗、人机。
- `scripts/rules/demo_abilities.gd`、`expanded_abilities.gd`：原有和新增卡池能力实现。
- `scripts/duel_view.gd`：交互、私有预付、查看面板、行动卡面、阶段提示和设置。
- `scripts/duel_hand_card.gd`：双方手牌展示、右键查看和拖动入口。
- `scripts/duel_table.gd`：3D 战场与鼠标选牌；每张牌堆高度 0.012；桌垫区域中心由 MAT_SLOTS 配置。
- `scripts/main.gd`：菜单和组卡器；顶部 `battlefield_background` 可修改桌垫图片。
- `docs/卡牌数据库与编写说明.md`：如何改数值、添加能力和登记卡牌。
- `docs/游戏整体开发计划.md`：状态说明、实现范围和后续工作。
- `开发者日志.md`：每轮开发记录。

当前可用范围是 61 张卡的本地人机对局与本地调试；本批 46 张新卡已登记规则效果。全牌表、梦违运行时加入、通用复制/替代框架、联网和独立导出仍属后续计划。


## 关于与调试

主菜单进入「关于」，显示居中的「这是测试文字」。在页面直接用英文输入 `multicolor`，无需输入框或回车，即开启调试。页面出现「退出调试模式」可关闭；模式只存在本次运行，重启默认关闭。进入下一场对战时应用当前模式。

调试对局公开双方手牌。顶部「操作：你／人机」指示当前由你操作的一方；调度、凭依、出牌、付款、攻击、阻挡和响应按当前执行权或选择所属方切换，人机不自动代打。人机手牌也从上方手牌区拖出使用。三档响应仍按原定义工作。

「你的牌库」「人机牌库」可随时打开整副剩余牌库，保留正在进行的付款和选择。右键查看卡图和文字，角落可观察战场，再返回选择。

「调试」打开右侧区域列表，可切换双方及来源区域。也可直接点场上的牌堆，滚动找到卡牌，按住卡面拖到所属玩家的战场、颜色盘、手牌或牌堆区域。拖动时列表暂时收起，松开后恢复；右键或拖到无效位置取消。放入战场后自动排列。

调试拖放直接移动现有实例，不付款、不进入堆叠，不触发进场、离场、死亡或计时替代效果。拥有者保持；自机区仅接收本局所选自机，普通符卡不能驻场，单位仍受容量和同称号限制，衍生物离场消失。必须先完成或取消正在进行的选择和支付。正常从手牌拖出使用仍遵循原规则，并正常触发卡牌效果。调试只改变当前对局，不改保存的卡组。

## 新增卡效果的操作

模式、额外费用及非战场目标通过「选择目标」列表声明，确认付款前可以取消。异星弹幕先选第一项再选第二项，可重复。触发能力出现「选择」；单一单位目标也可直接点击战场上的蓝边单位。桑尼进场可选择自身、己方或对方合法单位，选定后能力进入堆叠，结算后目标本回合获得疾行。可选触发可以「不使用」。墓地卡可在墓地列表发动；满足条件时，Hell's Tokamak 可从「牌库可用牌」使用。结晶、贫乏、奇迹、计时与先制已接入本批卡的规则。

新卡清单与绑定见 `docs/新增卡片导入清单-v0.9.md`。卡图统一显示尺寸，原文件保持不变。
