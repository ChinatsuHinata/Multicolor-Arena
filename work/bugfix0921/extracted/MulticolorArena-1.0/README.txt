multicolor:arena 1.0 · Windows 64 位（2026-09-21 测试问题修复）

完整解压到可写入的本地文件夹，再运行 MulticolorArena.exe。
MulticolorArena.exe 和 MulticolorArena.pck 保持同目录，无需安装 Godot。
包含486条卡牌记录及卡图（含兼容旧卡组的异版记录）、四副保存卡组，未包含开发者的联机身份和回放。

首次运行会在 EXE 旁创建 deck/预设卡组（四个 .mdeck）和 replay 文件夹。
分享卡组：把 .mdeck 发给对方，放入 deck 后重新进入编辑牌组即可看到。
保存卡组后更新对应文件；旧个人卡组首次自动迁移，原文件保留。
回放：单局人机、BO1 或整场 BO3 结束后询问保存；主界面“对局回放”播放。
.mreply 保存在 replay 文件夹，记录录制端可见信息，用同一版游戏播放。

本次修复卡牌颜色费用、异能时机、死亡检查、指示物与要石显示、联机入房提示。
新版规则与旧发行包不兼容，双方与观众都需使用这一份完整更新包。

联机：两名玩家使用同一包，房主建房，另一人加入并获得房主接受。
观众点击“观战”，最多4人，隐藏双方手牌和牌库，不能操作对局。
观战端口为对战端口+1（默认47862），独立限速，不等待观众确认。
检测掉线后锁住操作，30秒内重连继续；超时掉线方整场判负。
房主失联时客机结果注明“本地记录”；朋友间网络互断可能有结果分歧。
详见 Portable-Guide.md、LAN-Guide.md、VPN-Guide.md。
真实双机/三机与异地网络仍需在实际设备验证。

传输检查：ZIP旁 CheckTransfer-bugfix0921.cmd 检查压缩包；
完整解压后 VerifyFiles.cmd 检查 EXE/PCK。均为只读检查。
若本地通过、U盘或接收电脑失败，请重新复制并排查传输/存储环节。
