# 局域网双机测试 · multicolor:arena 1.0

本次增量更新以[卡组分享、观战与回放](Portable-Guide.md)为准：`.mdeck` 与 `.mreply` 位于 EXE 同目录；观战使用对战端口加1；断线30秒改为整场判掉线方负。

两台电脑使用同一份发行包，解压后保留 exe 和 pck 在同一目录。此版本使用 ENet 局域网直连，不需要平台账号；异地公网中继尚未接入。

## 开始一场对局

1. 两台电脑连接可互通的同一局域网。首次 Windows 弹窗允许游戏访问专用网络。
2. 主界面打开「联网对战」，输入各自显示 ID。
3. 房主选择 BO3（或 BO1）、是否检查卡组、端口，点击「创建房间」。通常保留「所有网卡」即可。
4. 另一位玩家点击房间列表的房间。未发现时，在「输入地址加入」中填写房主显示的一个内网 IP，端口与房主一致。
5. 房主接受申请。两人各选卡组并点击「选择此卡组」，然后双方「准备」。每局自动投硬币，正面房主先手、反面客机先手；结果在战场展示并进入对局记录，双方不能手动指定。
6. 开始后双方各自操作自己的手牌；付款推荐、替换与取消仍是本地预选，点「发动」后才提交。

## 建议核对的项目

- 起手调度、凭依、过阶段：双方显示相同回合与优先权，手牌数量一致，只看到自己的手牌。
- 付款：取消金边资源后重新选择，右键取消；对方不应看到卡牌被使用或资源被横置。正式发动后只扣一次费用。
- 战斗：双方分别宣攻、阻挡；再尝试多单位阻挡、伤害分配和先制。血量、死亡和触发效果应一致。
- 堆叠：使用符卡、用高速符卡响应、再反制；双方堆叠顺序、目标箭头与结算结果应一致。
- 触发与区域选择：进场触发、牌库检索、墓地回收、可不支付颜色使用等需要确认的效果。
- BO3：战场设置的「本局投降」只让对方赢当前这一局。未有人赢两局时，结果窗口点「下一局」进入准备，可在「调整主副卡组」中换牌；自机、主卡组张数及登记总牌池保持不变。双方准备后投新硬币并开局；正常计分两胜结束整场；断线超时另按整场判负处理，没有「整场认输」入口。
- 硬币：两端结果、先手和后手红薯应一致；断线重连不重投。可用两次不同玩家的单局投降，检查1:0、1:1，再进入第三局。
- 网络延迟：房间和战场右上角显示「你 / 对手」的ms值，约每2秒刷新。数值是双方分别测得至对端的往返时间（RTT），并非到游戏平台的延迟；两者因采样时间不同可略有差异。首次显示「测量中」，断线显示「已断开」，恢复后重新测量。更新数值不应打断当前选牌或付款。

## 断线与恢复

- 分别断开客机和房主网络：检测断线后，在线一方的出牌、支付、调度、回合推进均锁定，但可右键预览、查看墓地和战场。10秒内恢复应保留原状态；倒计时满30秒应终止整场，掉线方判负，超时后不能手动恢复。
- 可分别在付款前、已入堆叠、触发选目标、先制伤判后断开。恢复后检查费用、随机结果、生命、堆叠及待选状态，不能重复扣费或重掷。
- 重连期限内可在联机页面点「重连上次房间」。如果房主地址变了，先填新 IP。超过30秒应提示对局已结束，不能恢复。
- 重连期限内，关闭房主程序后重新打开，在联机页面点「恢复房主对局」；客机重连原席位。两端均要保留各自本机的联机身份记录。房主不能迁移至另一位玩家；恢复记录丢失则不能还原原局。
- 「离开房间」及退出程序会被对手视为掉线，超过30秒判整场负。恢复记录会保留，但超时终止记录禁止继续该对局；创建新房间会替换房主的上一份恢复记录。

## 反馈时请记录

2026-09-21 修复包增加入房状态与持久错误提示：持续“正在连接房主”通常尚未建立连接；“等待房主接受”说明握手已到达，需要房主接受申请。版本拒绝会提示双方校验摘要，请双方使用同一份完整 EXE/PCK。首次连接超时会退出等待并显示地址和端口。选卡组在成功入房之后进行，进不去房间时先记录这些提示。

双方所在阶段、刚操作的卡名、各自看到的生命值/堆叠、问题出现在哪一侧、是否发生过断线。截图尽量包含整张战场及对局流程记录。发行版的联机恢复记录位于 Godot 的游戏用户数据目录下的 `lan` 子目录，其中含恢复令牌及隐藏牌信息，不必公开上传整份记录。

## 验证边界

开发侧使用本机独立 Godot 进程测试；真正双机、Windows 防火墙、不同路由器/热点、无线隔离以及不同分辨率的组合，由本次实际双机测试继续确认。不能互通的访客 Wi-Fi 或启用 AP 隔离的热点需要更换网络；仅广播受限而 IP 互通时可用地址加入。

不同家庭网络或跨城市可通过通用虚拟局域网建立虚拟IP后，使用地址加入。步骤与平台条件见[虚拟局域网异地联机](VPN-Guide.md)，不需要上架游戏平台。


## 1.0 换备牌与断线验收

- BO3局间点“调整主副卡组”，确认显示卡图、左侧完整预览、自机以及主副卡组；右侧无全卡池，只有“更换完成”。点击或拖动互换，不能删除卡牌或修改自机。
- 故意使主牌不足50（开启检查时）或副牌超过10，点“更换完成”应留在编辑页并提示。换足后提交应返回房间，双方下一局使用换牌结果；原保存卡组不变。关闭检查时仍保持登记主牌张数和牌池。
- 已准备时先“取消准备”才能改牌；一方尚在换牌时不能自动开下一局。
- 掉线30秒期限从游戏检测断线开始计时，约6.5秒心跳检测延迟不含其中。查看战场不延长期限，重连失败不重置倒计时。已结束对局保留查看入口，不能出牌、准备或继续下一局。
- 双方必须使用1.0同一包，0.x未结束对局不兼容；已有个人卡组首次迁移至 EXE 同目录 deck，设置沿用原存档目录。
