# 已入库卡图

本目录存放已经写入游戏的卡牌图片，使用稳定卡牌ID命名，例如 `177.png`。

- 卡图：本目录内的 `ID.png`、`ID.jpg` 等原始图片。移动后内容保持不变。
- 卡牌规则：项目的 `cards/ID.json`，其中“图片”指向本目录。
- 可用卡池：`scripts/card_database.gd` 的 `IDS`，只登记已完成规则实现的卡牌。
- `卡图索引.json`：已登记卡牌的名称、定义路径、图片路径及SHA256，供核对与维护。

`recourse/新增卡片` 是待处理区，不是运行时数据库。把图片放进待处理区不会自动增加游戏卡牌。已完成批次见下方版本记录；之后新放入的卡图不自动导入。

后续获得导入指令时：先确定稳定ID，将本批指定卡图从待处理区移动至本目录并按ID命名，再编写JSON和能力实现，通过测试后登记ID。同步处理Godot图片导入配置，最后运行 `tools/check_card_database.py --write-index` 更新清单，再用不带参数的检查确认一致。不会因为更新清单而新增任何卡牌ID。

不要把已入库图片放回待处理区或删除；换图时替换对应ID的图片，并核对更新清单。
